# Lessons

What working on the project taught: a correction of the owner, or a practice that proved useful. One line per lesson, written when it happens: its date, the lesson, and where it may go (this project, the template of a Rust desktop application, a skill, an agent). Read only by the retrospective (step 22 of the [roadmap](../roadmap.md)), which sorts each one into the template, this project's `CLAUDE.md`, its skills or its agents, or drops it.

- 2026-10-31: run the checks with their exit codes written out (`cargo clippy …; echo CLIPPY=$?`), never piped into `| tail` within an `&&` chain: the pipe hid a Clippy failure once. Template (`CLAUDE.md`, Development).
- 2026-11-01: before a probe that takes the focus or sends keys or clicks on the owner's desktop (`xdotool`, the application sending keys), tell them how long it takes and to let go of the keyboard and the mouse, wait for their go, then a 3-2-1 countdown and an end notice as desktop notifications (`notify-send`), since the output of a command isn't shown live. Template (`CLAUDE.md`, a desktop application).
- 2026-11-01: the archive of a merged step goes as the first commit of the next step's pull request, never in a pull request of its own: one merge per step. Already in this project's `CLAUDE.md` and in the templates.
- 2026-11-01: on critical code (the guardrails of an external service, the matching of game data), run the code review again after applying its fixes, with a test per fix, until no high or medium finding is left. Template (`CLAUDE.md`, Code review).
- 2026-11-01: the CI of the pull requests built Linux only, so that code written for Windows or macOS alone was never compiled before a release; Clippy on Windows and macOS added in step 14a2. Template (CI).
- 2026-11-01: screenshots of the application itself, reliable under Wayland, with a temporary patch that asks egui for one (`ViewportCommand::Screenshot`), removed once looked at. Template (a skill, or `CLAUDE.md`, Interface design).
- 2026-11-01: keep `outputs/` small: delete what is no longer needed (old code review notes, previews) as soon as it is used. Template (`CLAUDE.md`, Working folders).
- 2026-11-01: tell the owner when a step turns out to need a finer split than planned (14a into 14a1 and 14a2), rather than growing its pull request. Template (`CLAUDE.md`, Specifications and roadmap).
- 2026-11-01: check the behaviour of a third-party tool in its source before stating it (the Ctrl+D of Exiled Exchange 2 read in `PriceCheckWindow.vue` and `Shortcuts.ts`). Template (`CLAUDE.md`).
- 2026-11-01: a mock-up at the default width of the window can show what the owner's wider window hides (a sentence on 3 lines for them, 4 at 420 px): look at both widths. Template (`html-mockups` skill).
- 2026-11-01: check the platforms the product targets against the real service before coding for one (Path of Exile 2 has no macOS client, `"mac": false` on Steam), so that its cost is weighed with the owner first. Template (`CLAUDE.md`).
- 2026-11-01: choose the license with the owner when the project starts, not by default: the templates write `MIT OR Apache-2.0`, while the owner wanted the GPL 3.0 for this application (a better fork must give its code back), found only before the first release; the code published meanwhile stays under the first license. Template (a question of the creation of a project, `README.md`, `Cargo.toml`).
- 2026-11-01: a test the owner runs by hand (in the game, on the desktop, a probe build) gets a step-by-step guide in `outputs/` (why, before starting with the exact command to launch, each test with its expected result, a table of results to fill), not instructions in the chat: given in the chat, the owner didn't see that the probe had to be launched first. Template (`CLAUDE.md`, Working folders, or a skill).
- 2026-11-01: a throwaway probe of the riskiest unknown (an X11 window over the fullscreen game) in a worktree, never pushed, before the wireframe: half an hour that settled what the design could rely on (no focus taken, clicks kept). Template (`CLAUDE.md`, Specifications and roadmap).
- 2026-11-01: the interface never names a competitor, even in a help text (owner). Template (`CLAUDE.md`, Interface design).
- 2026-11-01: on concurrent code (the threads of the hotkey, the clipboard and the interface), design who decides what before coding (one judge, an instant carried with the item): two of the six code reviews of 14b1 came from my own fixes of timings. Template (`CLAUDE.md`, Development, or the `code-reviewer` agent).
- 2026-11-01: end each hand test guide with a free test ("try your own scenarios"): in the probe of 14b2, the owner found on their own a case no test asked for (Ctrl+D on A, a filter typed, B, then A again: the filters lost). Template (`CLAUDE.md`, Working folders, or the skill of the test guides).
- 2026-11-01: a stand-in type for the other systems (`#[cfg(not(target_os = "linux"))]`) is built the same way on every system (`new()`), never with `default()`: Clippy refuses `default()` on a unit struct, an error seen only by the CI of Windows and macOS, since their Clippy can't run here (`ring` needs their C compiler). Template (`CLAUDE.md`, Development).

Template (`CLAUDE.md`, Working folders, or the skill of the test guides).
