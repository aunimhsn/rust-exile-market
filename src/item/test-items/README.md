# Test items

Items copied in Path of Exile 2, read by the tests of the parser (`../parser/tests.rs`).

| Files | Source |
|---|---|
| `fr-*.txt` | Copied in the French game client by the owner (Ctrl+C, advanced descriptions), October 2026. |
| `en-owner-*.txt` | Copied in the English game client by the owner (Ctrl+Alt+C), October 2026. |
| `en-*.txt`, except `en-owner-*` and `en-plain-*` | The test items of [Exiled Exchange 2](https://github.com/Kvan7/Exiled-Exchange-2) (`renderer/specs/Parser/items.ts`, MIT license), copied in the English game client. |
| `en-plain-*.txt` | Written by hand: the format without the advanced descriptions, and cases not met yet (an unidentified jewel with its description, a large stack). |

The texts of the items belong to Grinding Gear Games.
